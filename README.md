# AI 视频生成工作台（多中转站网页版）

## 统一素材存储

工作台支持将所有中转站的本地图片、音频和视频统一上传到腾讯云 COS，再把稳定的 HTTPS 地址发送给各中转站。配置文件位于 `.workbench-data/cos-config.json`，该目录已被 Git 忽略，密钥不会进入源码包或 GitHub。

在本机配置 COS 存储桶并启用后，无需再为每家中转分别填写素材上传地址；中转站自带的上传接口和 Uguu、Litterbox、Tmpfiles 只在未配置 COS 时作为旧版兼容路径。存储桶名称和访问凭据仅保存在本机配置中，不随源码发布。

一个在本机运行的 AI 视频生成工作台，用来统一管理多个 API 中转站、项目素材、提示词引用和视频生成任务。

当前内置适配：

- FMGO / 飞猫
- Paipu / Lec API
- CLMM Mall（动态读取 `/api/pricing` 视频模型，支持 SD2.0 / SD2.5）
- Pidoi（`sora-v3-933-pro`、`tejiasd` 等）
- ViralE
- CanSeeDream / 看见梦想
- LWAIGC
- Panda626（实时读取模型和分辨率；结果保留24小时）
- Baoju / aimjbbb（使用 `bj_live_` Key，实时读取模型、能力和积分价格；成片同步就绪后支持鉴权下载）
- MEAICC / 林木森AI
- Ziyu AI / 紫域AI
- GlobalAiOpc / 全球AI
- MaxForAI
- 通用 New API 中转站

## 主要功能

Baoju 的公开接口位于 `https://aimjbbb.cn/api/v1`。在“中转站管理”选择 Baoju / aimjbbb，填写本站账号 Key，再点击“测试并读取模型”；模型 ID 原样保留。文档未提供素材上传接口，本地素材沿用工作台已配置的 COS/图床。任务提交保留原幂等编号和请求快照，恢复时不会换编号；结果 `retrieving` 期间继续轮询，只有 `ready` 且有下载结果才标记完成。下载使用本站鉴权内容接口，跳转到对象存储/CDN 时不转发 Key。过期结果不会加入托管自动重新生成队列。

- 多个中转站配置的新增、编辑、删除、连接测试和自由切换。
- 根据中转站和模型自动调整时长、清晰度、比例、素材数量、种子和同步音频选项；所有 SD2.0 路线在工作台端统一放行 9 图、3 音频、3 视频，具体兼容性由上游返回。
- 支持图片、音频、MOV、MP4 和公网素材 URL。
- 本地素材在开始生成时自动转换为中转站可接收的临时 HTTPS 地址；填写自定义上传地址后优先使用自定义服务。
- 支持选择现有项目文件夹并“一键参考”。
- 按提示词中的 `【本节出场的所有人物】`、`【本节的所有背景】`、`【本段角色声线锁定】` 匹配同名图片和音频。
- 编辑时显示易读的 `@文件名=提示词名称`，提交时自动转换为中转站识别的 `@ImageN` / `@AudioN`。
- 提示词上方提供“固定内容”，每次请求自动添加到最前方，清空素材不会删除。
- 任务记录保存在免费的浏览器 IndexedDB 数据库中，每页只读取 10 条。
- 未完成任务按中转站要求分批查询；MEAICC 查询间隔保持在 20 秒以上，完成和失败任务停止轮询。
- 支持按任务状态、项目、关键词和 7 天前历史筛选。
- 同一时间只加载一个视频，收起、切换任务或翻页后立即释放视频内存。
- 支持任务记录 JSON 备份的导出和导入；备份不包含视频文件和 API Key。
- 创建任务的 POST 请求不会在结果不明时自动重发，避免重复扣费。
- 批量模式会先复用预上传素材，再按章节号使用“有序抢位”“限量抢占”或“严格顺序”提交；任务中心始终按章节号排列。
- 批量一键下载会按章节号逐条触发，并使用 `001-第077节-模型.mp4` 这类固定宽度文件名，避免下载完成顺序和文件名排序错乱。
- 支持按当前中转站导出浏览器与本地服务的分阶段诊断日志；日志不会保存 API Key、密码、提示词正文或素材 URL。

### 明星脸初筛

首次使用在源码目录运行 `./setup-face-screen.ps1`。脚本会在被 Git 忽略的 `.workbench-data` 中安装独立 Python 环境，并下载 OpenCV 官方 YuNet、SFace 模型。随后重启工作台，点击顶部“明星脸初筛”。

参考库可手动添加照片，也可在已安装分析组件后运行 `.workbench-data/face-venv/Scripts/python.exe importWikimediaFaces.py`，批量导入维基数据中有肖像、至少 5 个站点条目的内地、香港、台湾演员/歌手，以及有中文百科条目且中文姓名的新马演员/歌手。脚本只取 Wikimedia Commons 中有许可证信息、画面恰好检测到一张脸的照片，每人最多一张；照片、来源页面和许可证信息只保存在本机 `.workbench-data/face-library`。公开条目数及姓名形式只是范围筛选的粗略替代指标，不能证明覆盖了“三线以上”全部华语艺人；缺失人物仍需手动补充。首次筛查会建立人脸特征缓存，后续仅处理新照片。

如果来源站点提示访问限流，导入会停止并保留已经成功入库的照片；待限流解除后可重新运行，脚本会跳过已入库的人物。

选择本机视频后，页面最多均匀抽取 60 帧，本地服务将重复出现的人脸合并，按与参考照片的相似度列出人物及出现时间。参考照片和模型不会提交给视频生成中转站。候选分数仅供人工复核，未命中不代表能通过平台审核。声音、姓名和其他形象争议不在此功能的检查范围内。

参考照片仅作为本机筛查资料；若要展示、分享或发布照片，需逐张核对来源页的署名、许可证及人物肖像相关要求。

## 使用方法

1. 点击右上角“中转站管理”。
2. 选择中转站，填写自己的 API Key，点击“测试并读取模型”。
3. 测试成功后选择模型，再点击“保存并切换”。
4. 如需项目素材匹配，点击“选择项目文件夹”。选择文件夹本身不会上传文件，只读取文件名和基本信息。
5. 在“固定内容”中填写每次生成都要携带的画风、禁止项或一致性要求。
6. 把完整分镜提示词粘贴到“提示词 Prompt”。
7. 点击“一键参考”，检查自动匹配的图片、音频和中文 `@名称`。
8. 设置时长、清晰度、画面比例、数量和同步音频。
9. 点击“开始生成”。只有这一步才会上传本次使用的本地素材并创建中转任务。
10. 在右侧任务中心查看进度，点击任务后加载、播放或手动下载视频。

### 视频模型目录

- “测试并读取模型”以中转实时返回的目录为准，不再用内置名称名单过滤或补齐；接口明确返回空列表时，会提示检查 Key 权限或业务分组。
- 读取结果按中转配置、地址、接口类型和 Key 指纹保存在当前浏览器。保存配置后，重启会恢复匹配的目录和已选模型；更换 Key、地址或接口类型后需要重新测试。目录缓存不保存明文 Key。
- 实时接口暂时不可用时会明确提示：优先保留这把 Key 上次读取的目录，没有匹配缓存才显示内置参考列表；参考列表不代表 Key 验证成功。
- 新名称可以出现在目录中，但不等于已确认所有参数。已知模型保留专用规则；未公开能力的新模型会标注“参数能力待核实”，沿用该中转现有接口。如果上游更换了协议或字段，仍需按新文档适配。
- 此处是视频中转目录；文本推理使用独立的实时文本目录，图片生成仍使用已经适配的图片协议和模型选项。

## 批量提交与诊断日志

- “有序抢位”会先按章节号排序，每 350ms 发出一条请求，并受“最大同时在途”限制；速度优先，但中转站内部仍可能自行重新排队。
- “限量抢占”固定为最多 5 条同时在途，每 50ms 发出一条，适合限量线路开抢；只保证工作台发起顺序，不保证中转后台建单或完成顺序。
- “严格顺序”会等上一节拿到任务 ID 后才提交下一节，顺序最可靠但速度较慢。
- 遇到积分不足、余额不足、API Key 无效等确定性错误时，工作台会停止尚未发出的章节；已经在途的请求会等到返回，未提交章节可在处理账号问题后继续。
- 开始批量提交前会自动预上传本批次的唯一素材，相同素材在不同章节中复用；也可以提前点击“预上传全部素材”。
- MEAICC 等待确认超过 8 秒时会显示“可能已经进入中转，请勿重复提交”；创建任务最长等待 10 分钟。结果不明时不会自动重试，避免重复扣费；可用“章节号=任务ID”找回 `wr_...` 或 UUID 任务。
- 测试某家中转前可点击“清空本次日志”，测试结束后点击“仅导出当前中转日志”，在 Chrome 保存对话框中选择桌面或其他文件夹；导出的文件不包含其他中转。
- 日志中的 `materials_*` / `*_upload_*` 表示素材阶段，`provider_submit_started` 到 `provider_task_ids_received` 表示等待中转返回任务 ID 的阶段。
- 任务失败时会记录中转返回的失败码和失败原因；若中转未提供原因，日志会明确标记“中转未返回具体原因”。

## 一键参考的提示词格式

人物图片：

```text
【本节出场的所有人物】
孙桂兰
陈卫东
```

场景图片：

```text
【本节的所有背景】雪夜防火瞭望屋、雪夜山林防火道
```

人物声线音频：

```text
【本段角色声线锁定】
孙桂兰：中年女性，中低音，略带沙哑。
陈卫东：中年男性，声音虚弱干涩。
```

项目图片或音频使用相同的文件名，例如：

```text
孙桂兰.png
陈卫东.png
孙桂兰.wav
陈卫东.wav
雪夜防火瞭望屋.png
```

没有匹配文件的名称会保持原文，不会强行添加错误素材。

## 文本推理

- 顶部“文本推理”进入 CanSeeDream 的独立文本模块；图片、视频任务会继续运行。
- 填入文本专用 `sk_txt_` Key，点击“读取文本模型”，从实际目录选择模型和它支持的 Responses、Messages 或 Chat Completions 协议。视频、图片 Key 不通用。
- 输入文本后接收流式回答；显示中转公开返回的思考内容与实际 usage，不估算最终扣费。模型售价和消费账单在 [文本服务页面](https://see.ximeiedu.org/text-service) 查看。
- “上传文件 / 图片”可一次选择多个 TXT、MD、JSON、CSV、TSV、LOG、DOCX、PDF、PNG/JPG/WEBP 文件；文本在浏览器读取，DOCX/PDF 由本机服务提取正文，点击开始推理才发送给中转。文档排版和内嵌图片不发送，扫描 PDF 不自动 OCR；旧版 DOC 请先另存为 DOCX。
- 图片分别使用三种协议的原生图片内容格式；目录明确不支持图片的模型会阻止提交，未声明能力的模型需按中转说明选择。工作台附件上限：文档/文本单文件 10 MiB、图片单张 5 MiB、整个请求 20 MiB；超限会提示，不会静默截断。预览只显示前 2000 个字符，推理发送完整正文。
- 文档解析使用独立进程，超过 30 秒会终止读取并提示拆分文件；解析进程设置 V8 堆预算，但不代表整个进程的内存硬上限。较复杂的文档可能无法在工作台限制内提取。
- 文本不进入媒体任务队列，不轮询媒体任务。输入与回答仅保留在当前网页内存，刷新前请复制需要保存的内容。
- 断线或“停止接收”不代表上游未生成、未计费；不会自动重新提交。“恢复原请求”使用同一 Key、参数和幂等标识；缓存失效时先核对账单，主动提交新请求可能再次收费。
- Key 默认只存当前浏览器会话，可明确选择记住；不复用媒体 Key，也不写入服务器任务日志或备份。

## 任务备份

- 点击“导出备份”可以保存全部任务记录及轻量提交台账，包括已删除任务保留的受理记录；导入时不会把仅台账记录恢复成任务。
- 点击“导入备份”可以恢复任务记录。
- 相同任务编号会更新，不会重复添加。
- 备份不包含视频、参考素材或 API Key。
- 下载标记随任务编号保存在浏览器数据库中，单条、批量和托管下载使用同一记录。请用同一浏览器配置和相同工作台地址恢复；更换端口、`localhost` / `127.0.0.1` 或清除网站数据会进入不同或空的本地存储。
- 清除浏览器网站数据前建议先导出备份。

## 模型提交台账

- 在“成本统计 → 模型提交台账”按中转站、模型、项目和提交日期查看已受理次数及 task ID，支持导出 CSV。
- 同一上游 task ID 只计算一次，新 ID 的主动重做或自动重试另计；删除任务仍保留轻量台账。同节追加次数不等于重复扣费证据，生成失败也不代表已退款。
- 现有任务会回填台账；过去已经彻底删除的任务可能无法回填。手动找回但尚未核实的 ID 不计入已受理，实际扣退以中转账单为准。

## 素材上传说明

- 视频和音频参考通常需要公网 HTTP(S) 地址。
- 未填写素材上传地址时，工作台优先使用 Uguu，再回退到 Litterbox 和 Tmpfiles，生成约 1–3 小时有效的 HTTPS 直链；Litterbox 在本次服务运行中连续失败两次后自动熔断跳过。
- 自定义上传地址在“中转站管理 → 高级素材上传设置”中填写。
- `.mov` 按视频文件处理；常见音频格式包括 MP3、WAV、M4A、AAC 和 FLAC。
- 项目文件夹中未匹配到的文件不会上传。

## 数据与安全

- API Key 默认只保存在当前浏览器会话中；用户也可以按中转站选择在当前浏览器记住 Key。
- API Key 不会写入源码、任务备份或 Git 仓库；公共电脑不应启用“记住 Key”。
- 中转站普通配置、固定内容和任务记录保存在本机浏览器中。
- `.workbench-data`、运行密钥、临时上传文件、日志和 `node_modules` 不应上传 GitHub。
- 不要在截图、聊天或公开仓库中泄露 API Key。
- 工作台不会继承 `HTTP_PROXY` 等环境变量代理；系统网卡/TUN/VPN 仍可能接管本机 Node 服务的网络请求。
