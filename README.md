# AI 视频生成工作台（多中转站网页版）

## 统一素材存储

工作台支持将所有中转站的本地图片、音频和视频统一上传到腾讯云 COS，再把稳定的 HTTPS 地址发送给各中转站。配置文件位于 `.workbench-data/cos-config.json`，该目录已被 Git 忽略，密钥不会进入源码包或 GitHub。

当前电脑已配置香港 COS 存储桶 `ai-video-workbench-assets-1418205891`。启用后，无需再为每家中转分别填写素材上传地址；中转站自带的上传接口和 Uguu、Litterbox、Tmpfiles 只在未配置 COS 时作为旧版兼容路径。

一个在本机运行的 AI 视频生成工作台，用来统一管理多个 API 中转站、项目素材、提示词引用和视频生成任务。

当前内置适配：

- FMGO / 飞猫
- Paipu / Lec API
- CLMM Mall（动态读取 `/api/pricing` 视频模型，支持 SD2.0 / SD2.5）
- Pidoi（`sora-v3-933-pro`、`tejiasd` 等）
- ViralE
- CanSeeDream / 看见梦想
- LWAIGC
- MEAICC / 林木森AI
- Ziyu AI / 紫域AI
- GlobalAiOpc / 全球AI
- MaxForAI
- 通用 New API 中转站

## 主要功能

- 多个中转站配置的新增、编辑、删除、连接测试和自由切换。
- 根据中转站和模型自动调整时长、清晰度、比例、素材数量、种子和同步音频选项；所有 SD2.0 路线在工作台端统一放行 9 图、3 音频、3 视频，具体兼容性由上游返回。
- 支持图片、音频、MOV、MP4 和公网素材 URL。
- 本地素材在开始生成时自动转换为中转站可接收的临时 HTTPS 地址；填写自定义上传地址后优先使用自定义服务。
- 支持选择现有项目文件夹并“一键参考”。
- 按提示词中的 `【本节出场的所有人物】`、`【本节的所有背景】`、`【本段角色声线锁定】` 匹配同名图片和音频。
- 编辑时显示易读的 `@文件名=提示词名称`，提交时自动转换为中转站识别的 `@ImageN` / `@AudioN`。
- 提示词上方提供“固定内容”，每次请求自动添加到最前方，清空素材不会删除。
- 任务记录保存在免费的浏览器 IndexedDB 数据库中，每页只读取 10 条。
- 未完成任务按中转站要求分批查询；MEAICC 查询间隔保持在 20 秒以上，完成和失败任务停止轮询。
- 支持按任务状态、项目、关键词和 7 天前历史筛选。
- 同一时间只加载一个视频，收起、切换任务或翻页后立即释放视频内存。
- 支持任务记录 JSON 备份的导出和导入；备份不包含视频文件和 API Key。
- 创建任务的 POST 请求不会在结果不明时自动重发，避免重复扣费。
- 批量模式会先复用预上传素材，再按章节号使用“有序抢位”“限量抢占”或“严格顺序”提交；任务中心始终按章节号排列。
- 批量一键下载会按章节号逐条触发，并使用 `001-第077节-模型.mp4` 这类固定宽度文件名，避免下载完成顺序和文件名排序错乱。
- 支持按当前中转站导出浏览器与本地服务的分阶段诊断日志；日志不会保存 API Key、密码、提示词正文或素材 URL。

## 下载源码

### 方法一：网页下载

1. 打开本仓库首页。
2. 点击绿色的 **Code** 按钮。
3. 点击 **Download ZIP**。
4. 下载完成后解压到一个固定文件夹。

### 方法二：Git 下载

```bash
git clone 仓库地址
cd ai-video-workbench
```

这是私密仓库，下载或克隆时必须登录有权限的 GitHub 账号。

## 运行环境

- Windows 10 或 Windows 11
- Node.js 20 或更高版本
- pnpm
- Google Chrome 或其他 Chromium 浏览器

安装 pnpm：

```bash
npm install -g pnpm
```

## 开发模式启动

在源码文件夹打开 PowerShell 或终端，执行：

```bash
pnpm install
pnpm run dev
```

启动成功后打开：

```text
http://localhost:5173/
```

`pnpm run dev` 会同时启动网页和本地接口服务。使用期间不要关闭正在运行的终端窗口。

## 生产模式启动

```bash
pnpm install
pnpm run build
pnpm start
```

然后打开：

```text
http://localhost:8787/
```

## 使用方法

1. 点击右上角“中转站管理”。
2. 选择中转站，填写自己的 API Key，点击“测试并读取模型”。
3. 测试成功后选择模型，再点击“保存并切换”。
4. 如需项目素材匹配，点击“选择项目文件夹”。选择文件夹本身不会上传文件，只读取文件名和基本信息。
5. 在“固定内容”中填写每次生成都要携带的画风、禁止项或一致性要求。
6. 把完整分镜提示词粘贴到“提示词 Prompt”。
7. 点击“一键参考”，检查自动匹配的图片、音频和中文 `@名称`。
8. 设置时长、清晰度、画面比例、数量和同步音频。
9. 点击“开始生成”。只有这一步才会上传本次使用的本地素材并创建中转任务。
10. 在右侧任务中心查看进度，点击任务后加载、播放或手动下载视频。

## 批量提交与诊断日志

- “有序抢位”会先按章节号排序，每 350ms 发出一条请求，并受“最大同时在途”限制；速度优先，但中转站内部仍可能自行重新排队。
- “限量抢占”固定为最多 5 条同时在途，每 50ms 发出一条，适合限量线路开抢；只保证工作台发起顺序，不保证中转后台建单或完成顺序。
- “严格顺序”会等上一节拿到任务 ID 后才提交下一节，顺序最可靠但速度较慢。
- 遇到积分不足、余额不足、API Key 无效等确定性错误时，工作台会停止尚未发出的章节；已经在途的请求会等到返回，未提交章节可在处理账号问题后继续。
- 开始批量提交前会自动预上传本批次的唯一素材，相同素材在不同章节中复用；也可以提前点击“预上传全部素材”。
- MEAICC 等待确认超过 8 秒时会显示“可能已经进入中转，请勿重复提交”；创建任务最长等待 10 分钟。结果不明时不会自动重试，避免重复扣费；可用“章节号=任务ID”找回 `wr_...` 或 UUID 任务。
- 测试某家中转前可点击“清空本次日志”，测试结束后点击“仅导出当前中转日志”，在 Chrome 保存对话框中选择桌面或其他文件夹；导出的文件不包含其他中转。
- 日志中的 `materials_*` / `*_upload_*` 表示素材阶段，`provider_submit_started` 到 `provider_task_ids_received` 表示等待中转返回任务 ID 的阶段。
- 任务失败时会记录中转返回的失败码和失败原因；若中转未提供原因，日志会明确标记“中转未返回具体原因”。

## 一键参考的提示词格式

人物图片：

```text
【本节出场的所有人物】
孙桂兰
陈卫东
```

场景图片：

```text
【本节的所有背景】雪夜防火瞭望屋、雪夜山林防火道
```

人物声线音频：

```text
【本段角色声线锁定】
孙桂兰：中年女性，中低音，略带沙哑。
陈卫东：中年男性，声音虚弱干涩。
```

项目图片或音频使用相同的文件名，例如：

```text
孙桂兰.png
陈卫东.png
孙桂兰.wav
陈卫东.wav
雪夜防火瞭望屋.png
```

没有匹配文件的名称会保持原文，不会强行添加错误素材。

## 任务备份

- 点击“导出备份”可以保存全部任务记录。
- 点击“导入备份”可以恢复任务记录。
- 相同任务编号会更新，不会重复添加。
- 备份不包含视频、参考素材或 API Key。
- 清除浏览器网站数据前建议先导出备份。

## 素材上传说明

- 视频和音频参考通常需要公网 HTTP(S) 地址。
- 未填写素材上传地址时，工作台优先使用 Uguu，再回退到 Litterbox 和 Tmpfiles，生成约 1–3 小时有效的 HTTPS 直链；Litterbox 在本次服务运行中连续失败两次后自动熔断跳过。
- 自定义上传地址在“中转站管理 → 高级素材上传设置”中填写。
- `.mov` 按视频文件处理；常见音频格式包括 MP3、WAV、M4A、AAC 和 FLAC。
- 项目文件夹中未匹配到的文件不会上传。

## 数据与安全

- API Key 默认只保存在当前浏览器会话中；用户也可以按中转站选择在当前浏览器记住 Key。
- API Key 不会写入源码、任务备份或 Git 仓库；公共电脑不应启用“记住 Key”。
- 中转站普通配置、固定内容和任务记录保存在本机浏览器中。
- `.workbench-data`、运行密钥、临时上传文件、日志和 `node_modules` 不应上传 GitHub。
- 不要在截图、聊天或公开仓库中泄露 API Key。
- 工作台不会继承 `HTTP_PROXY` 等环境变量代理；系统网卡/TUN/VPN 仍可能接管本机 Node 服务的网络请求。
